# Cookie Jury

> Your expired browser cookies stand trial for privacy crimes.

A local web app imports your browser cookies and staging data, then assigns each one a charge, a lawyer, and a verdict based on how you actually browse. The twist is that a guilty cookie can only be released if you perform a bizarre penance like renaming a folder or donating a snack to a friend.

## Features
- Cookie import wizard that parses Chrome/Firefox exports into a searchable evidence board
- AI prosecutor generates one-sentence charges from domain, age, and tracking score
- Penance generator assigns physical or digital tasks to clear guilty cookies
- Animated gavel dashboard shows verdicts and tracks your clean-cookies streak

## Stack
- React
- Node.js
- Playwright
- SQLite

## Getting started
```
npm install && npm run dev
```
